# Выпуски и обновления

Готовые файлы находятся в [Releases](https://github.com/d3a0g/playspace-releases/releases). [Основной репозиторий](https://github.com/d3a0g/LauncherPlaySpace) содержит исходники и описание продукта. Списки изменений публикуются в релизах.

## Переход с 1.0.6

Прежний канал `latest.json` сохраняет формат 1.x и указывает на установщик 2.0 с SHA-256. Установка использует тот же Inno AppId, каталог и имя `LauncherPlaySpace.exe`, чтобы старый механизм обновления смог заменить и перезапустить приложение. При ручном обновлении закройте лаунчер и запустите установщик. Библиотеку можно скопировать кнопкой импорта в 2.0; исходный профиль 1.x сохраняется.

## Обновления нативной 2.0

В настройках откройте «Обновления PlaySpace» и проверьте новую версию. Канал `latest-v2.json` содержит URL установщика и подпись, привязанную к версии. Лаунчер проверяет подпись встроенным публичным ключом, загружает установщик с прогрессом, повторно проверяет подготовленный файл и запускает тихую установку. На время установки приложение закрывается и затем открывается заново. Активные игровые сеансы необходимо завершить.

Закрытый ключ подписи не входит ни в исходники, ни в архив приложения. Подпись обновления не является сертификатом издателя Windows Authenticode.

## Проверки релиза

До переключения latest подготавливаются черновики в двух репозиториях, загруженные файлы скачиваются и сверяются с локальными SHA-256. Проверяются native unit-тесты, frontend-сборка, desktop-сценарии и установка/удаление на изолированном пути. Испытания не подтверждают совместимость с каждой игрой, оборудованием или модом.
