## PlaySpace 2.1.0

- **Библиотека.** Поиск игр в выбранных папках, корзина, отмена объединения дубликатов, массовые действия и умные коллекции. Обнаружение VALORANT учитывает путь установки и сохраняет запуск через Riot Client.
- **Профили запуска.** Можно сохранить графические настройки, аргументы и выбранный набор модов для игры.
- **Сохранения.** Автоматические копии после игры, пропуск одинаковых копий, лимит версий и защита выбранных копий.
- **Моды.** Импорт и экспорт списка сборки Thunderstore с точными версиями, просмотр зависимостей и сообщения о конфликтах файлов. Добавлен импорт PACK для SHOGUN 2, Empire и Napoleon.
- **Настройки проекта.** Подписанный канал позволяет обновлять объявления, ссылки и доступность уже встроенных функций.

Windows 10/11 x64. Для обновления через лаунчер откройте «Настройки → Обновления PlaySpace». Для ручной установки используйте Setup, для запуска без установки — ZIP.

Проверки выполнялись на отдельном профиле. Поддержка конкретного мода зависит от версии игры и самого мода.
