# PlaySpace 2.0.0

Крупное обновление для Windows 10/11 x64: интерфейс React/TypeScript и нативные службы Rust/Tauri 2.

[Скачать последний выпуск](https://github.com/d3a0g/playspace-releases/releases/latest) · [Установка](../2.0/INSTALLATION.md) · [Моды](../2.0/MODS.md) · [Обновления](../2.0/UPDATES.md)

## Интерфейс и нативная основа

- Приложение переведено с Windows Forms на React/TypeScript/SCSS и Rust/Tauri. Системные операции не используют C#-bridge; .NET для приложения не нужен.
- Библиотека, рекомендации, мастерская и инструменты используют общую навигацию и основную область окна. Доступны сетка, список, подробное представление, размер обложек и собственные изображения.
- Основной интерфейс, инструменты и категории доступны на русском и английском, с сохранением языка. Отдельные технические сообщения могут оставаться на английском.
- Нативно реализованы запуск и учёт сеансов, статистика Steam, коллекции, сохранения, графические конфигурации, загрузки, перенос файлов, WARP, звуки, трей и большой экран с клавиатурой/Gamepad API.
- Улучшена загрузка обложек: локальный кеш Steam, несколько источников, точное название для игр без Steam ID и повтор после временной ошибки.
- Добавлена фоновая очистка записей подтверждённо удалённых игр с архивом полной записи. Недоступный диск, обновление Steam и активный сеанс не считаются удалением.
- Добавлены ссылки на поддержку [@PlaySpaceSupport_bot](https://t.me/PlaySpaceSupport_bot) и добровольную поддержку через [tips.tips](https://tips.tips/000492195). Приложение остаётся бесплатным.

## Мастерская: 78 адаптеров и Teardown

Каталог содержит **78 адаптеров: 36 Thunderstore, 37 локальных и 5 Paradox**. Доступны точные зависимости Thunderstore, предварительная проверка поддерживаемых архивов, учёт файлов, защита изменённых файлов при удалении и профили. Для Paradox предусмотрены зависимости и порядок загрузки локальных и уже скачанных Workshop-модов.

Teardown — новый адаптер для Steam App ID `1167630` и `teardown.exe`:

- Публичный Steam Workshop: поиск, категории Map/Gameplay/Asset/Vehicle/Tool, популярные/новые/лучшие и страницы по 30.
- Кеш метаданных на пять минут, сохранённые страницы и превью для офлайна. Размер и формат изображений проверяются; превью передаются как JPEG без расширения CSP.
- Открытие карточки в Steam; подписку и загрузку выполняет Steam.
- Отдельный импорт одного ZIP-мода с обязательным `info.txt`, включая папку-обёртку, в фактические Windows Documents/Teardown/mods.
- Предварительный план, журнал файлов и хеши. ZIP-моды доступны в профилях PlaySpace; Workshop-подписки в них не входят. Включать глобальные моды и запускать карты нужно в игре.

## Поставка и переход с 1.x

| Файл | Назначение |
| --- | --- |
| `LauncherPlaySpace-2.0.0-Setup.exe` | Единый Inno-установщик нативного приложения. |
| `LauncherPlaySpace-2.0.0-win-x64.zip` | Запуск после полного извлечения в отдельную папку. |
| `LauncherPlaySpace.exe` | Нативный Rust/Tauri EXE установленной или распакованной поставки. |

Нужен WebView2 Runtime. Cargo собирает `playspace-next.exe`; при упаковке файл переименовывают в `LauncherPlaySpace.exe`. Публичные исходники 2.0 содержат нативный проект без C# и bridge; прежняя реализация сохраняется в истории и приватных материалах.

Профиль 2.0 остаётся `%LOCALAPPDATA%/io.playspace.next.local`, чтобы сохранить данные локальных сборок. Профиль 1.x `%LOCALAPPDATA%/GameLauncherPRO` не удаляется. Кнопка импорта **копирует библиотеку**. Настройки 1.x, Steam-секреты и административные разрешения автоматически не переносятся; Steam нужно подключить отдельно. ZIP хранит профиль отдельно от приложения.

Переход старого клиента использует совместимый `latest.json`; подписанные нативные обновления 2.x — `latest-v2.json`. Оба пути используют Inno-установщик. Нативный updater проверяет подпись пакета по доверенному ключу при настроенном канале; URL и ключ задаются при сборке. Подпись updater не является Windows Authenticode. **Кодовая подпись Windows не подтверждена.**

## Проверки и известные ограничения

Для релизной сборки прошли **44 Rust-теста**, **3 TypeScript-теста**, production-сборка frontend и desktop-сценарии настоящего WebView2/IPC. Проверены библиотека, коллекции, безопасный тестовый процесс и учёт его сеанса, изображения, категории/сортировки Workshop, вторая страница, кеш/офлайн, отклонение неверных Steam-идентификаторов, RU/EN и окно 900 px. Установка и удаление ZIP-модов проверены на изолированных файлах; отдельный сетевой smoke Workshop также пройден.

На изолированном пути проверены свежая установка/удаление, зарегистрированный переход 1.0.6 → 2.0.0, повторный запуск нативного EXE по флагу обновления, прогресс и сохранение профиля/посторонних файлов. Подпись установщика и привязка к версии проверены; повреждённый файл отклоняется. ZIP прошёл проверку CRC и совпадения EXE. WebView2 уже присутствовал на тестовом ПК, поэтому ветка установки отсутствующего Runtime не выполнялась. Windows Authenticode и полный сетевой сценарий обновления рабочего пользовательского клиента не подтверждены.

- **Реальные игровые сессии, запуск Teardown и подписка на Workshop не тестировались.** Совместимость отдельных модов и всех 78 адаптеров с настоящими играми не подтверждена.
- Физический геймпад не проверялся; Gamepad API и клавиатурная навигация не заменяют аппаратный тест.
- Графические DLL, UniversalDLSS5 и WARP требуют отдельных проверок на целевом оборудовании. Прирост FPS и работа экспериментальных функций не гарантируются.
- Полное соответствие 1.x не заявляется: глубокий поиск произвольных EXE по дискам, все прежние темы/настройки доступности и расширенная очередь не перенесены полностью.
- Канал нативной 2.0 настроен на подписанные пакеты. Для первой 2.0 проверены подпись, установщик и совместимые параметры обновления; полный пользовательский цикл «загрузка новой версии → установка» потребует следующего выпуска.

## English

PlaySpace 2.0 replaces Windows Forms with a React/TypeScript UI and native Rust/Tauri 2 services. Russian and English UI, an integrated library and tools, Steam statistics, mod profiles, save backups and cached recommendations are available without .NET.

The catalog contains **78 adapters: 36 Thunderstore, 37 local and 5 Paradox**. The new Teardown adapter offers public Workshop browsing and separate single-mod ZIP import. Steam handles subscriptions and downloads; PlaySpace ZIP profiles do not control them. Enable global mods and launch maps in Teardown itself.

Download `LauncherPlaySpace-2.0.0-Setup.exe` or `LauncherPlaySpace-2.0.0-win-x64.zip` from [Releases](https://github.com/d3a0g/playspace-releases/releases/latest). Run the native `LauncherPlaySpace.exe`; Windows x64 and WebView2 are required. Installation and updates use Inno Setup. Legacy clients use `latest.json`; native 2.x signed updates use `latest-v2.json` with a configured trusted key. Updater signatures do not establish Windows Authenticode signing, which remains unverified.

The profile remains `%LOCALAPPDATA%/io.playspace.next.local`. Legacy library import copies data from `%LOCALAPPDATA%/GameLauncherPRO` without changing the old profile. Legacy settings, credentials and administrator permissions are not automatically migrated.

Release checks passed: 44 Rust tests, 3 TypeScript tests, production builds, native WebView2/IPC scenarios, installer signature/version binding and rejection of a tampered file. Isolated fresh installation, registered 1.0.6-to-2.0.0 upgrade, native restart and uninstall preserved profile and unrelated files. ZIP mod tests used fixtures. Missing-WebView2 installation, real gameplay, Steam subscriptions, physical controllers and a complete future-version network update were not tested. Full feature parity with 1.x and universal compatibility are not claimed.
